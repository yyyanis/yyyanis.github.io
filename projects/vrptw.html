Vehicle routing with time windows

A delivery company has a limited fleet, trucks with a capacity, and clients who accept deliveries only at certain hours: the vehicle routing problem with time windows, which is NP-hard. We built an instance generator and compared four solving methods with an OR-Tools reference on 150 instances.

Fig. 1

The problem

Plan one route per truck so that every client is served inside its time window, without exceeding capacity, for the shortest total distance.

Fig. 2

Six constraints

We formalized the problem as a graph with six constraints that every valid solution must respect.

Fig. 3

Four methods, one referee

Every method solves the same seeded instances, so each experiment can be rerun identically. The attention model splits large instances into clusters before routing.

Fig. 4

Gap to the reference

Median gap to OR-Tools by instance size. Simulated annealing is excellent on small instances but degrades fast; the attention model stays around 40% at 200 clients and answers in under a second.
