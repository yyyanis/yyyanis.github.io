Game of Life

Conway's Game of Life is a grid of cells that live or die according to four rules. We built it in C++ with an object-oriented design, so the same simulation runs in a terminal or in a graphical window, and we wrote it with as little AI help as possible.

  • C++
  • SFML

  • File input

Fig. 1

The four rules

Every cell looks at its eight neighbours. Four rules decide what happens at the next generation; everything else on screen comes from them.

Fig. 2

A grid without edges

The grid is toroidal: a cell on the right edge has neighbours on the left edge, and the same for top and bottom. Patterns never hit a wall.

Fig. 3

How it fits together

A pattern comes from a file or from the built-in list. The grid holds the cell states, the rules compute the next generation, and either view displays it.
