Hospital data warehouse

A decision-support data warehouse built on hospital activity data. We modeled it as four star schemas, loaded it with Talend jobs into PostgreSQL, and pseudonymized patient identifiers before they reach the warehouse. The project is still running.

Fig. 1

From source files to the warehouse

Talend jobs extract and clean the data, replace patient identifiers with pseudonyms, then load the star schemas in PostgreSQL.

Fig. 2

Four star schemas

Each subject area has its own fact table. Dimensions are shared between schemas, so results can be compared across them.

Fig. 3

Partitioning and bucketing

On the Cloudera stack, tables are partitioned and bucketed so queries read less data. I checked the data before this step.

Fig. 4

Pseudonymization

Identifiers are hashed with SHA-256 and a secret salt. The same patient always gets the same pseudonym, so analysis still works, but nobody can trace it back without the salt.
